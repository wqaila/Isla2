# zjy10 —— Anime Voice Lab

**Windows + RTX 5070 + GPT-SoVITS 的动漫角色声线复刻与可控语音生成系统。**

> ⚠️ **目前只有规划文档，尚无代码。**

---

## 这是什么

不是简单的"文字 → AI 声音"，而是一个完整的**角色声线复刻与可控语音生成系统**：

```text
选择角色 → 选择情绪 → 调整声线参数 → 输入台词
    → GPT-SoVITS 生成 → 后处理 → 声音评价 → 自动调参 → 最终语音
```

目标形态是一个可管理多角色、保存声线、控制情绪、生成并自动优化的本地平台。

## ⚠️ 数据不入库

本目录的 `.gitignore` 排除了全部数据目录：

```
models/      模型权重（动辄几 GB）
dataset/     数据集（原始 / 分离 / 清洗 / 切片 / 标注）
outputs/     生成的音频
history/     生成历史
characters/  角色资料（参考音频、情绪参考、微调模型）
configs/     本地配置
```

**仓库里只放代码和文档，数据留在本地。**

有两条理由，第二条容易被忽略：

1. **体积** —— 模型权重动辄几 GB
2. **权益** —— 参考音频如果来自动漫角色，实际是**配音演员的声音**，
   不适合随公开仓库分发

详见 [`声音生成.md`](声音生成.md) 第四十七节「版权与合规」。

> 注意：推送脚本**不读 `.gitignore`**，上述路径在推送工具里也单独配了一份排除。
> 新增数据目录时要**两处都配**。
