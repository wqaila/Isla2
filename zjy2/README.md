# 次元萌盒（赛博玩具 AI · 硬件原型）

面向二次元与科技爱好者的桌面级 AI 互动玩具，核心定位是「沉浸式二次元陪伴」——
能看、能听、能说、能陪你「闹腾」的二次元伙伴。
