Phase 1b · 辅助工具

zjy5 — 视频工具集

为语料采集提供技术支持，从视频中自动提取台词文本

🎬
辅助工具

视频台词识别工具 + B站下载器（空）

基于 OpenCV + PaddleOCR + Whisper 的综合台词提取工具，同时支持画面OCR和语音识别双通道，为后续模型训练准备高质量语料。

📄 核心文件

chibtaici/main.py (562行)
台词识别主程序：支持faster-whisper/openai-whisper语音识别+PaddleOCR画面识别，含交互式OCR区域设置、简繁体自动转换、智能文本过滤去重、合并去重等完整管线
chibtaici/ocr_region_selector.html (463行)
可视化OCR区域选择网页：上传视频截图→鼠标框选字幕区域→自动计算相对坐标→一键复制命令行参数
chibtaici/requirements.txt
依赖清单：PyTorch CUDA 11.8、PaddleOCR GPU 2.7.0、faster-whisper、OpenCV 4.6等
bilibili_downloader/
空目录（B站视频下载器未开发）

🔧 命令行参数

参数说明
--video视频文件路径（必需）
--output输出台词文件路径
--whisper_modelWhisper模型大小：tiny/base/small/medium/large
--ocr_regionOCR识别区域相对坐标 x1,y1,x2,y2
--ocr_intervalOCR帧间隔（越大越快）
--use_faster_whisper启用 faster-whisper（更快更轻量）
--disable_ocr / --disable_voice单独禁用OCR或语音识别
--interactive_ocr交互式命令行设置OCR区域

Phase 3 · 核心训练

zjy7 — 爱莉希雅 LoRA 微调项目 ⭐

将产品概念落地为实际的AI角色模型——基于 Qwen2.5-7B 训练崩坏3角色"爱莉希雅"

🎯
LoRA微调

爱莉希雅 AI角色扮演模型训练管线

完整的模型训练生产线：从原始台词数据处理→LoRA微调训练→模型合并转换为GGUF→Ollama部署。已修复20+问题，训练管线成熟稳定。

📄 核心文件

prepare_data.py (377行)
数据预处理引擎：知识库55条+同义提问变体+高频QA重复+拒答/角色保护样本20条+台词加权打分匹配+5轮多轮对话上下文+数据质量校验
train_lora.py (264行)
LoRA训练主程序：4-bit NF4量化加载、7模块训练(q/k/v/o/gate/up/down)、EarlyStopping、验证集评估、断点续训支持、完整日志系统
post_train.py (273行)
后处理管线：LoRA合并→GGUF F16转换(含chat_template)→量化(llama-quantize)→推理测试，支持灵活跳过各步骤
evaluate.py (260行)
模型评估：Perplexity计算+角色一致性(16题)+多轮对话测试+脱角色检测(4个诱导题)
deploy_ollama.py (116行)
Ollama Modelfile自动生成器，支持自定义温度/top_p/上下文长度
data_stats.py (91行)
训练数据统计分析：长度分布、类别分布、回复长度直方图、重复检测
train_config.json
集中配置：LoRA(r=32/alpha=64/dropout=0.15)、训练(2epoch/lr=1e-4/bf16)、所有路径
Modelfile
Ollama部署配置：system prompt定义爱莉希雅人设
README.md (285行)
完整项目说明：配置说明、各脚本详解、命令行参数、已修复问题清单(20+)

Phase 5 · 最终系统

zjy9 — 爱莉希雅 AI 完整聊天系统 ⭐⭐

集大成之作——整合所有前置项目成果，打造生产级多端AI聊天系统

🌸
完整系统

爱莉希雅 AI — 本地LLM聊天系统（集大成）

整合人设注入+RAG记忆+情感引擎+用户学习+多端客户端+公网隧道的完整AI聊天系统。支持Ollama本地推理和6家云端API智能切换，Android/树莓派/浏览器均可连接。

🖥️ PC 服务端核心模块

server/main.py (1,370行)
FastAPI主入口：REST API(30+端点)+WebSocket+管理面板+速率限制+Token认证+全局异常处理+优雅关闭
server/ollama_client.py (440行)
Ollama客户端：动态num_predict、5层防重复检测(句/短语/中块/大段/字频)、实时截断、MAX_OUTPUT_CHARS硬限制
server/elysia_prompt.py (159行)
爱莉希雅人设：三层性格体系+8组Few-Shot示例+时间感知注入+严格反重复指令+摘要输出约束
server/memory.py (589行)
RAG记忆系统：双后端Chromadb/TF-IDF、自动事实提取(30+模式)、记忆衰减(30天/90天)、自动清理、多集合管理
server/emotion_engine.py (650行)
情感引擎：7维分析(关键词+句式+标点+否定词四层)、趋势追踪、情绪自适应Prompt、AI回复一致性检查
server/user_learning.py (1,278行)
用户学习：记忆神经网络(节点+边+权重衰减)、LLM辅助深度分析、5大特质评估、多设备独立画像、个性化上下文注入
server/cloud_client.py
云端API客户端：6家提供商(DeepSeek/OpenAI/通义千问/智谱/Kimi/自定义)
server/database.py
SQLite数据库：4张表(会话/消息/连接日志/系统日志)
server/time_context.py
时间上下文感知：动态分析当前时段、会话时长、对话节奏

📱 客户端

android/ (Kotlin+Compose)
Android客户端：WS/WSS双协议、指数退避自动重连、消息操作(复制/重发/重新生成)、发送状态指示、深色/浅色主题、配置持久化
rpi_client/ (Python)
树莓派客户端：WebSocket连接+命令行交互工具(elysia_cli.py)+一键安装脚本
server/static/index.html
Web管理面板：仪表盘/聊天测试/Ollama设置/云端API/服务设置/日志/连接设备，7个功能页面
