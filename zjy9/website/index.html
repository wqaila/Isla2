Core Features

核心功能

从底层推理引擎到上层智能交互，打造全方位的 AI 聊天体验

🧠

智能模型路由

支持 Ollama 本地模型和 6 大云端 API（DeepSeek/OpenAI/通义千问/智谱/Kimi/自定义）。Auto 模式自动切换，优先本地、云端兜底，保证服务永不中断。

💬

双通道聊天

同时支持 REST API（SSE 流式输出）和 WebSocket 实时通信。流式响应逐字推送，体验流畅自然。

🎭

角色人设注入

内置爱莉希雅完整角色人设 System Prompt + 5 组 Few-Shot 示例对话，自动注入到每一次 AI 推理中，确保回复风格一致、充满角色魅力。

💾

RAG 记忆系统

双后端记忆架构（TF-IDF / ChromaDB），支持语义搜索对话历史。自动提取用户关键信息（姓名、偏好等），让 AI 记住每一次对话。

💗

情感识别引擎

7 种情绪多维分析（喜悦/悲伤/愤怒/恐惧/惊讶/厌恶/中性），实时情绪趋势追踪，根据用户情感状态自适应调整回复策略，更具同理心。

🎓

用户学习引擎

记忆神经网络持续学习用户画像——基本信息、性格特质、沟通风格、兴趣偏好。LLM 辅助深度分析，知识图谱自动关联与衰减。

🌐

公网访问支持

集成 Cloudflare Tunnel，免费将服务暴露到公网。自动 HTTPS/WSS 加密，无需配置路由器或防火墙，随时随地访问。

🛡️

安全防护机制

可选 API Token 认证、IP 级速率限制（通用 120次/分钟，聊天 60次/分钟）、CORS 中间件、全局异常处理，全方位保障服务安全。

📊

Web 管理面板

完整的单页管理面板，支持仪表盘实时统计、聊天测试、模型配置、云端 API 管理、日志浏览、设备监控，所有操作可视化。

Quick Start

快速开始

三步启动你的 AI 聊天服务

1️⃣

启动 PC 服务端

双击 server/start.bat 一键启动，或命令行运行 python server/main.py。服务将监听在 http://localhost:8080

2️⃣

确保 Ollama 运行

运行 ollama serve 启动本地推理服务。或配置云端 API Key 使用 DeepSeek 等在线模型

3️⃣

连接客户端

打开 Web 管理面板 /dashboard 测试聊天，或使用 Android App / 树莓派客户端连接

Optimization

防重复输出优化

针对小模型容易陷入重复循环的问题，实施多层防护策略

⚙️

生成参数优化

repeat_penalty 提升至 1.8，repeat_last_n 扩大至 256 tokens，num_predict 限制为 150，Tail Free Sampling 启用

📝

Prompt 防重复指令

System Prompt 中内置严格禁止重复段落，从源头引导模型避免循环输出

🔍

5 层实时检测

句子级、短语级、中等块、大段落、字符频率——5 层递进式重复检测，每 30 字符检测一次，触发即自动截断

🛑

硬字符限制

输出超过 500 字符时强制截断，作为最后一道防线，确保不会出现超长重复输出
