# 音色诊断报告：为什么"不像爱莉希雅"

> 触发：用户反馈 Phase 0 导出的样本"根本就不像是角色卡中的角色所说的音色，讲得和机器人一样"
> 日期：2026-11-09
> 方法：全部为本机实测，含频谱/基频/平坦度客观测量 + 4 组对照实验

---

## 一、结论摘要

用户的主观判断是对的，客观数据支持这个结论。但**根因不是模型不行，是参考音频选段不当 + 文本前端缺失**。

| # | 发现 | 证据 | 影响 |
|:-:|---|---|---|
| 1 | **参考音频选的是"亢奋表演腔"** | 素材 F0 中位 317Hz，选段 366Hz（+49Hz，处于 p90 附近） | 合成音色整体偏高、偏尖 |
| 2 | **参考文本是亢奋语气的台词** | "努力维持优雅美丽可爱…这可是身为副首领最重要的职责呀" | 模型学到的是表演腔而非日常语气 |
| 3 | **文本前端完全未启用** | `text_frontend = ''`，日志 `no frontend is avaliable` | 数字/符号/停顿处理缺失，韵律生硬 |
| 4 | 换参考音频能改善音高 | 1.4.mp3（F0 253Hz）→ 合成 F0 318Hz（接近素材中位） | 证明选段是关键变量 |
| 5 | 素材本身音色一致 | 42 个 30s 窗口质心变异系数仅 0.048 | 排除"混入其他说话人" |
| 6 | 素材经过噪声门处理 | 5.24% 帧是纯数字零（-180dBFS） | 呼吸声/气声被切除，听感机械 |
| 7 | 采样率正确，不是重采样错误 | 源 44.1kHz → 参考 24kHz，F0 一致（353 vs 355Hz） | 排除重采样嫌疑 |
| 8 | RL 模型无实质改善 | base 与 rl 的质心差 +490 vs +478，几乎一样 | 不必切换权重 |

**一句话**：模型有能力克隆（用参考文本原句合成时质心差仅 −56Hz，几乎完全匹配），但**换文本后音色就漂移到 +490Hz**——而参考音频本身又选了个偏尖的表演段，两个因素叠加，听起来就像"机器人在模仿"。

## 二、关键证据

### 2.1 决定性实验：复述参考文本 vs 换新文本

同一套参考条件，只改合成文本：

| 合成文本 | F0 | 质心 | 与参考的质心差 |
|---|---|---|---|
| 参考音频原句（复述） | 352.9Hz | **2857Hz** | **−56Hz** |
| 全新文本「今天天气真不错…」 | 369.2Hz | 3403Hz | **+490Hz** |

**解读**：复述时几乎完美复刻（差 56Hz 在测量误差范围内），换文本就漂移 490Hz。

这说明：
- 模型的克隆能力没问题
- 问题是**泛化到新文本时音色控制不稳**
- 参考音频的质量与代表性直接决定泛化效果

### 2.2 参考音频的选段问题

21 分钟素材的基频分布：

```
全局 F0: 中位 317.3Hz   p10 238.4Hz   p90 404.6Hz
```

当前选段（174.89–184.59s）：

```
F0 中位 366.4Hz   ← 落在 p90 附近，比素材中位高 49Hz
```

对比其他短片的 F0：

| 素材 | 内容 | F0 | 判断 |
|---|---|---|---|
| 1.4.mp3 | "这么晚了还不睡吗，是在想我对不对" | **252.6Hz** | 偏低，接近温柔私语 |
| 1.3.mp3 | "快去休息了，约好了我们在梦里相见" | 296.3Hz | 温柔 |
| 1.5.mp3 | "睡不着的话就来聊聊天吧" | 303.8Hz | 温柔 |
| 1.6.mp3 | "晚上好，如此美妙的夜晚" | 315.8Hz | 接近中位 |
| **当前参考** | "努力维持优雅美丽可爱…" | **369.2Hz** | **最高，亢奋** |
| 1.1.mp3 | "这么早起床是为了能早点见到我吗" | 358.2Hz | 偏高 |

**当前选的是全素材里音高最高、最亢奋的一段**。zjy13 的选段逻辑按"信噪比 + 时长"打分，**完全没有考虑音高代表性和语气**——这是选段策略的缺陷。

### 2.3 换参考音频的实测效果

同一句合成文本，只换参考：

| 参考 | 参考F0 | 合成F0 | 合成起伏 | 合成质心 |
|---|---|---|---|---|
| R0 当前参考 | 369.2Hz | 366.4Hz | 0.183 | 3455Hz |
| 1.0.mp3 | 340.4Hz | 363.6Hz | 0.165 | 3683Hz |
| **1.4.mp3** | **252.6Hz** | **317.9Hz** | 0.124 | 3867Hz |
| 1.5.mp3 | 303.8Hz | 342.9Hz | **0.194** | 3459Hz |

**1.4.mp3 的合成 F0 是 317.9Hz，正好等于素材全局中位 317.3Hz** —— 证明选段对音高有决定性影响。

但注意：1.4 的合成质心反而更高（3867Hz）。说明"音高"和"音色亮度"是两个独立维度，不能只看 F0。

### 2.4 文本前端缺失

```
text_frontend = ''
```

加载日志里有被淹没的一行：`no frontend is avaliable`。

`cosyvoice/cli/frontend.py:56-75` 的三级回退：
1. `ttsfrd` —— 未安装
2. `wetext` —— **已安装，但初始化失败**（尝试下载资源时 modelscope 返回 403 无 token）
3. 空 —— 完全不做文本规范化

影响：中文的数字、符号、停顿、语气词处理全部走裸文本路径，韵律自然度受损。这与"像机器人"的听感直接相关。

### 2.5 素材经过噪声门处理

```
静音帧（RMS < 1e-9）占比: 5.24%
```

**5.24% 的帧是纯数字零**——真实录音不可能有绝对的零，这说明素材经过噪声门（noise gate）或强降噪处理。

后果：呼吸声、气声、语句间的自然衔接被切除，只剩下"干净的浊音段"。这类素材克隆出来会**缺少人声的自然感**，听起来机械。

这也解释了为什么参考音频的 8k 以上高频能量比官方示例高 11dB（−23.4 vs −34.5dB）——降噪处理常伴随高频残留或锐化。

### 2.6 排除的假设

| 假设 | 验证 | 结论 |
|---|---|---|
| 重采样错误 | 源 44.1kHz，参考 24kHz，F0 353 vs 355Hz 一致 | ❌ 排除 |
| 素材混入其他说话人 | 42 窗口质心变异系数 0.048 | ❌ 排除 |
| 参考文本与音频不对应 | zjy13 文档记录 ASR 回读逐字一致 | ❌ 排除 |
| RL 模型更好 | base +490 vs rl +478，无实质差异 | ❌ 排除 |
| 混合调用模式（F2）导致音色退化 | 纯基线 A1/A2 与 F2 的质心 3403 vs 3289，F2 反而略好 | ❌ 排除 |

**重要**：混合调用模式（Phase 0 的情绪路径）不是音色问题的原因。它的质心 3289Hz 甚至比纯基线 3403Hz 更接近参考。情绪控制的方案本身没问题。

## 三、改进方案（按优先级）

### P0：换参考音频（立刻可做，成本最低）

**建议方案**：从短片中选温柔语气的段落，而不是从合集里按信噪比挑。

| 候选 | 文本 | F0 | 理由 |
|---|---|---|---|
| **1.5.mp3** | "睡不着的话就来聊聊天吧" | 303.8Hz | 温柔、贴近中位、起伏 0.197 自然 |
| **1.4.mp3** | "这么晚了还不睡吗，是在想我对不对" | 252.6Hz | 最温柔，但音高偏低较多 |
| 1.6.mp3 | "晚上好，如此美妙的夜晚" | 315.8Hz | 最接近素材中位 |

**推荐 1.5.mp3**：F0 303.8Hz 接近中位、F0 起伏 0.197 最自然（接近官方示例的 0.226）、内容符合角色日常语气。

**但这需要你听感确认**——客观指标只能筛掉明显不合适的，最终要靠耳朵。

### P0：启用文本前端

`wetext` 已安装但初始化失败（下载资源 403）。需要：
1. 检查是否能用本地资源初始化
2. 或配置 modelscope token
3. 或接受降级（但要在文档里明确标注）

这一项需要你确认是否愿意配置 token。

### P1：改进选段策略

当前 `prepare_voice_ref.py` 按"信噪比 60% + 时长 40%"打分，建议加入：
- **音高代表性**：F0 接近素材中位得分更高（惩罚极端值）
- **语气平坦度**：F0 起伏在 0.15–0.25 区间得分更高（排除亢奋/平淡）
- **排除噪声门痕迹**：检测纯零帧比例，过高则警告

### P1：参考文本选择

参考文本应该用**角色日常说话的语气**，不要用台词式表演腔。当前这段"努力维持优雅美丽可爱这三者之间恰到好处的平衡这可是身为副首领最重要的职责呀"明显是角色介绍式的夸张台词。

### P2：评估素材是否需要重新处理

5.24% 纯零静音说明素材被处理过。如果有**未处理的原始素材**，效果可能更好。请确认 `C:\Users\user\Desktop\aili` 是原始素材还是已处理版本。

## 六、对 Phase 2 的影响

这次诊断改变了 Phase 2 的优先级：

**原计划**：Phase 2 先做情绪映射，D1 盲听决定走路线甲/乙。

**现实**：音色本身就不对，情绪无从谈起。必须先修音色。

**建议调整**：
1. **Phase 2 拆成 2a（音色修复）和 2b（情绪控制）**
2. **2a 优先**：换参考音频 + 启用文本前端 + 改进选段策略
3. 2a 通过听感验收后，再做 2b

**好消息**：混合调用模式（情绪控制的实现方案）已证明不影响音色，技术上可行。等音色修好，情绪可以直接接上。
