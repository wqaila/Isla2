# 参考音频是否"不够"：量化结论

> 触发：用户反馈"确实更像角色，但还是感觉不够，是参考音频不够吗"
> 日期：2026-11-09
> 方法：用模型自带 campplus 说话人验证器算余弦相似度 + 文本完整性反推

---

## 一、直接回答

**不是参考音频不够长。** 有三条实测证据：

| 证据 | 数据 | 说明 |
|---|---|---|
| 拼接更多参考**没有提升** | 单段 1.0 = 0.8139；拼 2 段 = 0.8164；拼 3 段 20.2s = **0.7646** | 加长反而变差 |
| 客观相似度**已超官方基准** | 爱莉希雅长文本 0.9208 vs 官方合成 0.7559 | 数值上比官方示例还像 |
| 复述参考原句**几乎完美** | 0.9280（rl 模型 0.9361） | 模型能完全复刻 |

**但你的"不够"是真实存在的**，只是原因不是"量不够"，而是**参考文本标注不全**。

---

## 二、关键发现：2 个短片的文本标注残缺

用"语音段时长 × 正常语速 4.2 字/秒"反推应有字数：

| 音频 | 语音段时长 | 标注字数 | 应有字数 | 缺口 | 结论 |
|---|---|---|---|---|---|
| 官方参考 | 2.58s | 14 | 11 | −3 | 基本吻合 |
| 当前参考 | 8.53s | 42 | 36 | −6 | 基本吻合 |
| 1.0 | 4.46s | 18 | 19 | +1 | 基本吻合 |
| 1.1 | 4.35s | 15 | 18 | +3 | 基本吻合 |
| 1.3 | 3.77s | 16 | 16 | 0 | 基本吻合 |
| 1.4 | 3.69s | 16 | 15 | −1 | 基本吻合 |
| **1.5** | 4.78s | **11** | **20** | **+9** | **标注残缺** |
| **1.6** | 4.56s | **11** | **19** | **+8** | **标注偏少** |
| 1.7 | 4.27s | 17 | 18 | +1 | 基本吻合 |

**1.5 和 1.6 各少标了 8–9 个字。**

这解释了为什么：
- 1.6 相似度最低（0.6835）—— 它正是标注缺口最大的
- 1.0 相似度最高（0.8139）—— 它标注最完整
- 复述参考原句相似度 0.9280 —— 文本与音频长度匹配

### 为什么这会"像机器人"

CosyVoice 的 `prompt_text` 必须与参考音频**逐字对应**。

如果音频里说了 19 个字，却只标注 11 个字，模型学到的是：

> "这 11 个字对应这 4.5 秒的语音" → 即"每个字要拖 0.4 秒"

合成新文本时，这个错误韵律被套用，听起来就是**拖沓、机械**。

## 三、相似度全景数据

### 3.1 与官方基准对比

```
官方参考 vs 官方合成        0.7559   ← 模型在官方素材上的水平
爱莉希雅 长文本(比值1.08)    0.9208   ← 比官方还高
爱莉希雅 复述参考原句        0.9280   ← 几乎完美
爱莉希雅 短文本(比值0.21)    0.8568
```

**客观数值上，爱莉希雅的克隆效果优于官方示例。** 但你仍觉得不够——说明**相似度不是唯一维度**。

### 3.2 相似度衡量什么、不衡量什么

`campplus` 提取的是**说话人身份特征**（192 维），衡量"是不是同一个人"。

它**不衡量**：
- 语气、情绪、韵律节奏
- 说话的"味道"、习惯性停顿
- 音色的细腻质感

所以可能出现"相似度 0.92，但听起来不像"的情况——**身份对了，气质不对**。

### 3.3 拼接实验：加量无效

| 参考组合 | 时长 | 相似度 |
|---|---|---|
| E1 单段 1.0 | 6.1s | 0.8139 |
| E2 1.0+1.5 | 13.6s | **0.8164**（略高） |
| E2 1.5+1.6 | 14.0s | 0.8108 |
| E3 3 段拼接 | 20.2s | **0.7646**（反而降） |

**结论**：参考音频从 6s 加到 20s，相似度没有实质提升，甚至下降。

原因：拼接引入了更多"标注不全"的片段，稀释了质量。

## 四、真正的改进方向

按预期收益排序：

### P0：修正参考文本（收益最大）

**1.5 / 1.6 的文本必须补全**，否则它们不能用作参考。

**做法**：
1. 用 ASR 重新转写（zjy13 的 `.venv-asr` 是 Windows venv，WSL 用不了；需要在 WSL 装 FunASR，或用其他方式）
2. 或者人工听写——这几段都很短（7-9 秒），人工听写最可靠
3. 或者放弃这两段，改用标注完整的 1.0 / 1.3 / 1.4 / 1.7

**推荐**：先用 **1.0**（标注最完整，相似度最高 0.8139），不用 1.6。

### P0：当前参考其实是最好的

回顾数据：

| 参考 | 语速 | 相似度（长文本） |
|---|---|---|
| 当前参考（9.7s / 42字） | **4.33 字/秒** ✅ | 0.9208 |
| 1.0（6.1s / 18字） | 1.92 字/秒 | 0.8139 |
| 1.6（6.5s / 11字） | 1.22 字/秒 | 0.6835 |

**当前参考的语速是唯一正常的**，所以它的合成效果实际上**好于**那些短片。

之前判断"当前参考是亢奋段、音高偏高"，那是对的——但**语速正常 + 文本完整**这两个优点更重要。

### P1：多段参考覆盖不同语气（需要先修好文本）

如果文本补全了，可以用 2 段不同语气的参考拼接，覆盖更宽的韵律范围。

但**必须先修文本**，否则拼接只会引入更多错误。

### P1：接受模型能力边界

CosyVoice3-0.5B 是 5 亿参数的小模型。它的音色复刻能力有上限：
- 身份相似度能做到 0.92（很好）
- 但细腻的语气/韵律还原有限

**如果修完文本仍不满意**，可考虑：
- 换更大的模型（CosyVoice 有 300M/0.5B，更大需自行训练）
- 用 GPT-SoVITS（zjy10 的路线，专精音色克隆）
- 微调（需要素材和训练资源）

## 五、需要你确认

### 1. 关于"不够"的具体感受

这个很重要，决定优化方向：

- **A. 音色本身不对**（不像那个人）→ 客观相似度 0.92，理论上不会；若确实如此，可能是参考音频本身不典型
- **B. 音色对，但说话方式不像**（语气、节奏、味道）→ 这是韵律问题，需要修文本
- **C. 音质差**（沙哑、闷、机械）→ 是素材音质或声码器问题
- **D. 都差一点** → 综合问题

### 2. 是否人工听写 1.5 / 1.6 的完整文本？

这两段各 7-9 秒，听写成本很低。补全后它们的相似度可能从 0.68 提升到 0.85+。

### 3. 是否接受先用 1.0 作参考？

标注最完整、相似度最高（0.8139）。虽然语速偏慢（1.92 字/秒），但比其他几个好。
