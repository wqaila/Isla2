# 硬件规格与引脚（B 型确认版）

日期：2026-10-19  
型号：**ESP32-S3-Touch-LCD-1.85B**（用户已确认）  
来源：微雪官方产品文档外设速查表，实测抓取整理

## 1. 主控与存储

| 项目 | 规格 |
|---|---|
| 主控 | ESP32-S3R8，Xtensa 32 位 LX7 双核，最高 240 MHz |
| 无线 | 2.4 GHz Wi-Fi（802.11 b/g/n）+ Bluetooth 5（LE），板载贴片天线 |
| 内存 | 512 KB SRAM，叠封 8 MB PSRAM |
| 存储 | 外部 16 MB NOR Flash |
| 供电 | Type-C，或 MX1.25 2PIN 接 3.7 V 锂电池 |
| 外形 | 电子徽章造型，CNC 铝合金外壳 |

## 2. 显示与触摸

| 模块 | 器件 | 接口 | 地址 / 参数 |
|---|---|---|---|
| 显示 | ST77916 | QSPI | 360 × 360，RGB565，16-bit 色深 |
| 触摸 | CST816S | I2C | 7-bit 地址 `0x15` |

显示引脚：

| 信号 | GPIO |
|---|---|
| CS | 21 |
| PCLK | 40 |
| DATA0 | 46 |
| DATA1 | 45 |
| DATA2 | 42 |
| DATA3 | 41 |
| RST | 3 |
| BL（背光） | 5 |

触摸引脚：`SCL=10`，`SDA=11`，`RST=1`，`INT=4`。

|---|---|---|---|

| 音频输入 | ES7210 回声消除 + 双麦克风 | I2C + I2S | `0x80` |

| 信号 | GPIO |
|---|---|

| LRCK | 38 |
| DOUT（播放） | 47 |
| DIN（录音） | 39 |
| PA（功放使能） | 9 |

I2C 共享总线：`SCL=10`，`SDA=11`。

## 5. 关键约束

**PWR 电源键不支持自定义。** 官方文档明确：接 Type-C 或电池，长按 2 秒开关机，短按 1 秒开机。**不能把它当聊天录音键**，这是之前方案里已经提醒过的点，现在有官方依据。

**扬声器是焊盘，不是成品喇叭。** 板上引出扬声器焊盘，需要自己焊扬声器或接引出线。所以在买喇叭前要确认阻抗与功率，不要凭猜测下单。

**I2C 是共享总线。** 触摸、IMU、音频芯片、电量检测、RTC 都挂在 GPIO10/11 上，地址分别是 `0x15`、`0x6B`、`0x30`、`0x80`、`0x55`、`0x51`，互不冲突。初始化时注意不要重复占用总线。

**USB 与 UART0 是两条不同的调试路径。** Type-C 走原生 USB JTAG/串口；UART0 通过 SH1.0 4PIN 引出。第一版串口输入优先用 USB 这条，无需额外接线。

## 6. 对本项目的影响

第一版是文字版，只需要：

- 显示（ST77916 QSPI）
- 触摸（CST816S，第一版可不启用）
- Wi-Fi

**音频相关引脚先不初始化**，避免占用 I2S/I2C 资源。等 V2 做语音时再启用 ES8311 与 ES7210。

驱动实现应直接复用微雪官方 B 型示例，不要按本表手写 QSPI 时序。本表的用途是核对官方示例的引脚是否与本机实物一致。
